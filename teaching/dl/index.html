CS 402: Frontiers in Deep Learning #

Announcements

Spring 2026: Welcome! This course covers the latest advancements in Deep Learning. Prerequisites: Basic Machine Learning & Python/PyTorch proficiency.

Course Description #

This course provides a deep dive into modern deep learning techniques. While we start with the foundations, the focus is on state-of-the-art architectures including Transformers, Generative Models (Diffusion, GANs), and Large Language Models (LLMs).

Topics include:

  • Deep Feedforward Networks & Regularization
  • Convolutional Networks (CNNs) & Computer Vision
  • Sequence Modeling (RNNs, LSTMs, Attention)
  • Transformers & LLMs (BERT, GPT)
  • Generative Models (Diffusion Models, VAEs)
  • Deep Reinforcement Learning

Textbooks #

  • Primary Text (The "Flower Book"):
    • Deep Learning by Ian Goodfellow, Yoshua Bengio, and Aaron Courville. (Online Version)
  • References:
    • Dive into Deep Learning (Zhang et al.)
    • Recent conference papers (NeurIPS, ICLR, CVPR).

Grading #

  • Coding Assignments (40%): PyTorch-based implementations.
  • Midterm Exam (20%): Theory and concepts.
  • Final Project (40%): Research-oriented project in teams.
